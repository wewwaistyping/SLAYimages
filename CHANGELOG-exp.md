# SLAY Images 5.1.0-exp.1 — локальная экспериментальная сборка

Не для гита. Собрана поверх 5.0.1-beta.5. Всё ниже проверено только автотестами на коде (≈550 проверок) — в живой таверне и на телефоне ещё не запускалось. Поэтому чек-лист внизу.

## Что изменилось

### Деньги и сохранение картинок
- Пути с пробелами и апострофами в имени персонажа (`Denis  ALT`, `Roman 'Ro' Thorne`) больше не ломают запись пути в тег. Раньше «Продолжить» перегенерировало готовые картинки, а регенерация не сохранялась.
- Метка «ошибка» снимается после удачного повтора/регенерации. Картинки, у которых файл есть, а показывалась карточка ошибки, починятся сами при открытии чата.
- Старые битые картинки из версий до 4.3 (error.svg) снова не трогаются, как в 5.0.
- «Повторить» на карточке переписывает только свою картинку, а не все битые в сообщении.
- «Регенерировать картинки» под сообщением правильно находит картинки, даже если среди них есть карточки ошибок. Двойной тап по кнопке больше не запускает второй платный круг.
- Переключила чат, пока рисуется — картинка не пропадает: допишется, когда вернёшься в тот чат (будет уведомление).
- Свайп/регенерация/«Продолжить», пока рисуется предыдущая — новые теги теперь обрабатываются.
- Картинка пришла, а в таверну не сохранилась (телефон, связь) — загрузка повторяется 3 раза, потом картинка всё равно показывается и появляется кнопка «Сохранить ещё раз». Второй платный запрос не уходит.
- Регенерация в одном чате больше не подменяет ту же картинку в ветках/копиях чата.

### Телефоны
- Картинки в чате грузятся лениво (только когда долистал) и распаковываются в фоне. Видео не качаются все разом при открытии чата, запускаются при появлении на экране.
- Если «прошлую картинку в контексте» не удалось сжать — она не отправляется (раньше улетал оригинал на 20 МБ).
- Запасная копия рефов в браузере восстанавливается только если она новее серверной (удалённое на другом устройстве не воскресает).

### API, ошибки, Наистера
- Наистера: «вписать вручную» работает (имя приводится к виду из списка: строчные, дефисы → пробелы). Пункт Grok Pro убран. Рефы: grok и семейство nano banana.
- Gemini напрямую у Гугла: ключ уходит и во втором заголовке, который Гугл принимает.
- Ошибки: 403 больше не «ключ не подошёл», в тексте есть ответ провайдера; 429 — «лимит или баланс»; таймаут без «загляните в галерею»; отказы Gemini по-русски с причиной; карточка ошибки на телефоне не режет «Сервер ответил».
- Кнопка «Тест»: одно уведомление, зелёный только при реальном успехе; для своего URL ответы 401/403/404/405 показываются нейтрально («проверить можно только генерацией»).
- Профили подключения: удаление не применяет профиль; профили запоминают модель Наистеры.
- GPT: третий «Формат запроса» → **images/edits (GPT, с рефами)**. Рефы уходят файлами, модель обязательна, размер из соотношения сторон, настройки «Качество GPT» и «Точнее держать лица». Без рефов запрос не уходит (ошибка с объяснением). **Не проверено на живом сервере.**
- Галка «Иконка гардероба в окне чата» снова включает иконку.

### Гардероб
- ИИ-описание («Перегенерировать описание», «Сгенерировать ИИ», при загрузке): панель занята спиннером с крестиком, таймаут 2 минуты, повторный тап не запускает второй платный запрос. Закрыла гардероб — результат не теряется молча.
- Смена категории надетой вещи снимает её со старого слота.
- «Сохранить» во время замены картинки ждёт загрузку, старая картинка не остаётся.
- Импорт: проверка файла до кропа, дубликаты спрашивают «Добавить ещё раз?».
- В групповых чатах описание одежды не инжектится.

### Папки рефов (новое)
- В «Сохранённых» строка чипов `[Все] [папки…] [Без папки] [＋]`. Один персонаж может лежать в нескольких папках. Тап по выбранному чипу — меню папки. У персонажа кнопка 📁. При сохранении нового персонажа можно сразу выбрать папку.
- Внутри папки у персонажа открывается образ с такой же подписью.
- Ряд лиц больше не прыгает в начало после тапа.

### Стили (новое)
- ♥ на карточках стилей → чип «♥ Избранное». Карточка «＋ Свой стиль».
- Кнопка ⬇ на картинке и в полноэкранном просмотре: на ПК скачивает файл, на телефоне открывает «Поделиться».
- Тумблер «В тогл пресета»: выбранный стиль целиком записывается в выбранный тогл активного пресета (исходный текст тогла сохраняется, «Как в пресете» возвращает его). Только Chat Completion. Статус под строкой «Стиль».

### Меню настроек
- Вариант B: разделы свёрнуты, у каждого подпись-статус; сверху два тумблера «Генерация / Гардероб»; редкое уехало в «Ещё»; своё подключение гардероба для описаний — за галкой «Своё подключение»; длинные подсказки — за значком ⓘ.

## Чек-лист для проверки (сначала то, что про деньги)

ПК и телефон, если не сказано иначе.

1. Открой чат с персонажем, у которого в имени пробел или апостроф, нажми «Продолжить» на сообщении с готовыми картинками → картинки НЕ перегенерируются.
2. Сломай генерацию (неверный ключ) → карточка ошибки; верни ключ → «Повторить» → картинка появляется и после перезагрузки остаётся.
3. Сообщение с двумя картинками, одна битая → «Регенерировать картинки» → обе на своих местах.
4. Двойной тап по «Регенерировать картинки» → второе уведомление «уже генерируются», лишних запросов нет.
5. Запусти генерацию, переключись в другой чат, вернись → картинка на месте, было уведомление.
6. Запусти генерацию, сразу свайпни → в новом ответе картинка генерится.
7. Чат с большим числом картинок на телефоне → открывается быстрее, картинки подгружаются по мере скролла.
8. Наистера: выбери «— вписать вручную —», впиши `nano-banana-2-lite` → генерация идёт, модель в запросе `nano banana 2 lite`.
9. Наистера: Grok Pro в списке нет.
10. Ошибка 403 (если есть чем вызвать) → в тексте ответ провайдера, не «ключ не подошёл».
11. «Тест» с неверным ключом → одно красное уведомление, кнопка не зелёная.
12. Профили: удалить профиль → текущие настройки не меняются.
13. Галка «Иконка гардероба в окне чата» выкл/вкл → иконка исчезает и появляется сразу.
14. Гардероб → «Перегенерировать описание» → спиннер с крестиком; закрой гардероб во время — после ответа ничего не ломается; крестик отменяет.
15. Гардероб → смени категорию у надетой вещи → она снята.
16. Гардероб → импорт той же карточки второй раз → вопрос «Добавить ещё раз?».
17. Рефы → «Сохранённые» → «＋ папка» → назови → отметь персонажей → чипы фильтруют; тап по выбранному чипу → меню папки; 📁 у персонажа переключает папки; удаление папки ничего не удаляет.
18. Папка «Imperial» → у персонажа с образом «imperial» открывается именно он.
19. Тап по лицу в ряду → ряд не прыгает в начало.
20. Пикер стилей → ♥ на карточке → чип «♥ Избранное» появился; «＋ Свой стиль» → карточка с пометкой «мой».
21. ⬇ на картинке: ПК — файл скачался; телефон — открылось «Поделиться».
22. Пикер → тумблер «В тогл пресета» → выбери тогл → выбери стиль → в менеджере промптов текст тогла заменён; «Как в пресете» → вернулся исходный. Переключи пресет → статус просит выбрать тогл.
23. GPT images/edits (если есть ключ): Custom → формат edits → модель gpt-image-1 → генерация с рефом персонажа; без рефа — понятная ошибка.
24. Меню: все разделы свёрнуты, статусы в заголовках верные; открытые разделы помнятся после перезагрузки; «Генерация/Гардероб» тумблеры работают; ⓘ раскрывает подсказку.
25. Телефон: карточка ошибки читаемая, «Сервер ответил» не обрезан; чипы папок скроллятся вбок.

## Известные ограничения
- images/edits и «Поделиться» на айфоне не проверялись вживую.
- Стиль в тогл: менеджер промптов может не перерисоваться сам до переоткрытия панели (таверна не даёт к нему доступа).
- Видео, записанные старыми версиями, до первой регенерации всё ещё с autoplay.
- Если после ошибки сохранения свайпнуть/перезагрузить до «Сохранить ещё раз» — несохранённая картинка теряется.
